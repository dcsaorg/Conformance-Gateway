At the start of the conformance testing scenario, the DCSA reference implementation needs an existing Transport Document and a proposed amendment that can be used in the direct-amendment flow.

Use the examples below as templates and modify the values as needed for your system. You may use a Sea Waybill, Straight B/L, or Negotiable B/L. The original and amended Transport Documents must use the same Transport Document type, `isToOrder` value, and `transportDocumentReference`.
