At the start of the conformance testing scenario, the DCSA reference implementation needs a proposed amended Transport Document that can be used in the direct-amendment flow.

Use the example below as a template and modify the values as needed for your system. You may use a Sea Waybill, Straight B/L, or Negotiable B/L. A Transport Document with the same `transportDocumentReference` and `transportDocumentStatus` must already exist in your system.
